# NK Food Agro E-commerce Website

Open `index.html` in a browser.

Included:
- Responsive premium storefront
- Product cards and offers
- Add-to-cart drawer with quantity controls
- Mobile responsive layout
- Product image supplied in `assets/makhana.jpg`

The checkout button is a front-end demo. For real orders, connect a backend, payment gateway, database, shipping provider and WhatsApp/order API.
