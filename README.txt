Categories:

Each product supports 2 gallery images.

IMAGE NAMING:
Put product images in the assets folder using the names in script.js.
Example:
makhana-250g.jpg
makhana-250g-2.jpg

You can use PNG too by changing the extension in script.js:
"assets/makhana-250g.png","assets/makhana-250g-2.png"

The site automatically fits images with object-fit: contain, so different image sizes will display without cropping.

To add a new product, add another object to PRODUCTS in script.js.
